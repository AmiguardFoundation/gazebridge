## 🚀 The Vision
GazeBridge bridges the gap between physical struggle and digital literacy. Children with Oculomotor Apraxia (OMA) suffer from a permanent "visual storm" and horizontal visual crowding. By utilizing the smartphone's built-in gyroscope and the computational intelligence of **Google Gemma 4 AI**, GazeBridge creates a "Neural Lock" that stabilizes the visual pathway.

## 🧠 Scientific Pillars
1. **Stein’s Window:** Enforces a critical 800ms window of absolute postural quiet, allowing the lagging magnocellular pathway to reset and clear visual crowding.
2. **The Matryoshka Protocol:** Bypasses broken horizontal saccade pathways by splitting and stacking language vertically into a tiered reveal system (Semantic Shell -> Morphemic Frame -> Core Synthesis).
3. **The Mustafa Principle:** A manifesto for global health equity, moving clinical-grade neuro-rehabilitation from $10,000 lab hardware into a free mobile browser.

## 💻 Tech Stack & Metrics
* **Frontend Runtime:** Pure HTML5, TailwindCSS, Native Web Sensors API (`DeviceMotionEvent`).
* **Telemetry Processing:** First-order Infinite Impulse Response (IIR) Low-Pass Filter at ~60Hz to isolate true intentional OMA head thrusts from hardware noise.
* **AI Engine integration Layer:** Local Edge-AI classification model schema (Gemma 4 configuration targets).
