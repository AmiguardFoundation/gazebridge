## 🔬 Scientific References & Research

Our project is built on the shoulders of giants. GazeBridge is a direct software implementation of established cognitive neuroscience, eye-tracking paradigms, and motor-stabilization protocols. The architecture is mathematically tuned to accommodate the physical constraints of Oculomotor Apraxia (OMA) and related neuro-divergent reading profiles.

### 🛡️ Core Defense Matrix 

| Citation | Core Neuroscientific Discovery | Direct GazeBridge Implementation |
| :--- | :--- | :--- |
| **Stein (2001)** | The **Magnocellular Theory** proves reading layout efficiency is entirely dependent on timing signals in the brain's visual M-cells. | **High-Contrast Temporal Pacing:** Delivering synchronized sensory feedback frames to lock attention before text decapsulation. |
| **Rayner (1975)** | Text decoding is strictly bottlenecked by the physical size of the immediate central **foveal window**. | **Foveal Isolation:** Restricting screen display to 1–2 words at a time to shield the fovea from peripheral visual clutter. |
| **Rayner (1998)** | Reading efficiency relies on stable, stationary **fixations** and predictable horizontal **saccades**. | **Vertical Presentation:** Eliminating erratic horizontal tracking demands by delivering text vertically to accommodate OMA. |
| **Reichle et al. (1998)** | The **E-Z Reader Model** mathematically proves cognitive word decoding must finish *before* the brain commands the eyes to move. | **Adaptive Rate Control:** Locking presentation speeds (60–80 WPM) to match cognitive decoding limits and prevent motor meltdowns. |
| **Rayner (2009)** | Visual symbols and scene elements pre-attentively guide, capture, and prime **attentional allocation**. | **Visual Anchors:** Using targeted icons directly alongside high-friction vocabulary to prime semantic decoding. |
| **Dehaene (2009)** | The brain utilizes **neuronal recycling** to map abstract symbols to spoken words via dedicated visual routing. | **Phonon Synchronization:** Binding acoustic rhythms directly to visual milestones to accelerate lexical synthesis. |
